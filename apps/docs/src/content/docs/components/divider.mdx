**A thin rule that separates content.** Full-bleed or inset, horizontal or
vertical. Four boolean props, no events, no methods, no slots — and, unusually
for this library, **no `density` prop**.

## When to use

- Separating **interactive from non-interactive** areas of a container — a
  card's actions row from its content.
- Marking a **hierarchy** boundary in a list or menu, where whitespace alone
  isn't enough.

### When not to use

| Situation | Use instead |
|---|---|
| Spacing between unrelated blocks | Whitespace / margin |
| A section heading | A heading element |
| A decorative flourish | Nothing |
| A container edge | The container's own border or elevation |
| Every row of a list | Nothing — M3 warns against the clutter |
| A progress track | [`md-progress-indicator`](/components/progress-indicator/) |

## Insets

`inset` is exactly `inset-start` + `inset-end`. The distances come from
`--md-divider-inset-start` / `--md-divider-inset-end`, so an icon column that
isn't 16px wide is a one-property override, not a new variant.

| Need | Setting |
|---|---|
| Full-bleed rule | no attributes |
| Indented both ends (rows with leading icons) | `inset` |
| Indented at the leading end only | `inset-start` |
| Indented at the trailing end only | `inset-end` |

## Vertical

:::caution[A vertical divider needs a parent that resolves a height]
It has no intrinsic block size. In a flex row with the default
`align-items: stretch` it fills the row; under `align-items: flex-start` or
`center` it collapses to nothing and you see no rule at all.
:::

<ComponentDemo
  html={`<div style="display: flex; align-items: stretch; block-size: 40px; gap: 16px; padding: 0 16px; background: var(--md-sys-color-surface); border-radius: 12px;">
  <span style="display: flex; align-items: center;">Draft</span>
  <md-divider vertical></md-divider>
  <span style="display: flex; align-items: center;">Edited 2m ago</span>
  <md-divider vertical inset></md-divider>
  <span style="display: flex; align-items: center;">3 comments</span>
</div>`}

## In a list

M3's hierarchy rule in one demo: an **inset** rule groups rows that share the
icon column, a **full-bleed** rule marks the boundary between sections. Note
that the inset is pushed out to 56px so it lines up with the text, not with the
icon.

## Accessibility

- A purely **decorative** rule needs no role. It stays invisible to assistive
  tech, which is the correct outcome.
- Where the rule conveys a real **structural** boundary — between groups in a
  menu, say — add `role="separator"` on the host so the grouping is
  perceivable. Don't add it to every rule; that turns a visual nicety into
  screen-reader noise.
- Never let a divider be the *only* signal of grouping. Headings and
  `aria-label`led groups carry that meaning properly.

## RTL, density & i18n

**RTL** — `inset-start` / `inset-end` are logical, so they follow the document
direction automatically. See [RTL](/behaviour/rtl/).

**Density** — no `density` prop. Adjust `--md-divider-thickness` and the inset
properties directly.

**i18n** — the component renders no text, so there is nothing to translate.
Inset distances may still need revisiting if a translated icon column changes
width. The [responsiveness story](/storybook/?path=/story/containment-divider--responsiveness)
covers narrow containers, where a 16px inset eats a larger share of the row.

## Theming

| Custom property | Purpose | Default |
|---|---|---|
| `--md-divider-color` | Line colour | `outline-variant` |
| `--md-divider-thickness` | Line thickness | 1px |
| `--md-divider-inset-start` | Leading inset distance | 16px |
| `--md-divider-inset-end` | Trailing inset distance | 16px |

  <div style="padding: 12px 16px;">Thicker, primary-tinted</div>
  <md-divider style="--md-divider-thickness: 3px; --md-divider-color: var(--md-sys-color-primary);"></md-divider>
  <div style="padding: 12px 16px;">Last row</div>

  label="Themed instances"

A divider is one of the few components where the dark theme genuinely changes
the design decision, not just the colour: `outline-variant` sits much closer to
the surface on dark, so a rule that reads as a firm separator on light can all
but vanish. See the
[dark-theme story](/storybook/?path=/story/containment-divider--dark-theme).

**CSS part** — `divider`.

```css
md-divider::part(divider) {
  opacity: 0.6;
}
```
