Follow the progress of AWC UI Core and its developer tools. This page tracks
confirmed milestones; [GitHub releases](https://github.com/awc-ui/core/releases)
contain the full release history.

Last updated: **14 September 2026**.

## Shipped in 1.0.0

[AWC UI 1.0.0](https://github.com/awc-ui/core/releases/tag/v1.0.0) is available on
npm. These milestones are included in the stable release.

### First stable release

Core, framework integrations, tokens, theme tools, and MCP are published at 1.0.0.
[Release milestone #5](https://github.com/awc-ui/core/issues/5)

### MCP server and AI skills

A published documentation server, reusable build and review skills, and setup
instructions for AI assistants.
[Setup guide](/guides/building-with-ai/) · [Milestone #1](https://github.com/awc-ui/core/issues/1)

### Readable chart labels on mobile

Bar-chart value-axis labels adapt to the available width, with collision-aware
spacing and resize handling.
[Issue #8](https://github.com/awc-ui/core/issues/8)

### Mobile Watchlist scrolling

Core tables support native horizontal touch scrolling while keeping frozen
headers aligned. The Credit Risk Watchlist uses this fix.
[Issue #6](https://github.com/awc-ui/core/issues/6)

## Planned

## Deferred

**Documentation versioning** — implemented, then removed for now. The website
serves one current set of documentation. There is no scheduled return date.
[Milestone #3](https://github.com/awc-ui/core/issues/3)

## Suggest an improvement

- [Request a feature](/contributing/feature-requests/) and describe the workflow it would improve.
- [Propose a component](/contributing/new-component-requests/) with its expected behavior and use cases.
- [Report a bug](/contributing/reporting-a-bug/) with a reproducible example.

Check [existing issues](https://github.com/awc-ui/core/issues) before opening a new
request. A proposal becomes a planned milestone when its scope and priority are
confirmed.
