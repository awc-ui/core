## State Layer Tokens

| Token | Value | Usage |
|-------|-------|-------|
| `--md-sys-state-hover-state-layer-opacity` | `0.08` | Hover overlay |
| `--md-sys-state-focus-state-layer-opacity` | `0.12` | Focus overlay |
| `--md-sys-state-pressed-state-layer-opacity` | `0.12` | Press overlay |
| `--md-sys-state-dragged-state-layer-opacity` | `0.16` | Drag overlay |
| `--md-sys-state-disabled-container-opacity` | `0.12` | Disabled container |
| `--md-sys-state-disabled-content-opacity` | `0.38` | Disabled content |
