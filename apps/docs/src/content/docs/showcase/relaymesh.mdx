**Next.js · `apps/showcase-relaymesh` in the repository.** API observability console in dark theme: service health, latency charts, request log, incident timeline.

## Screens

- / — Services: fleet summary tiles + md-card grid with md-status-dot health, 24h uptime md-sparkline, alert md-badge (server-rendered DSD with client sparkline islands)
- /latency — Latency: md-line-chart p50/p95/p99 with deploy mark line + stacked md-area-chart regional traffic, both driven by md-segmented-button time windows (1H/6H/24H/7D)
- /requests — Request log: docked md-search with live suggestions panel filtering an md-table with expandable payload rows via md-table-expand-toggle
- /incidents — Incidents: md-list timeline with md-status-dot severity, md-chip tags, acknowledge via md-split-button + md-menu actions, md-snackbar confirmations
