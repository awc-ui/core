**Plain HTML (no build step) · `apps/showcase-hearthwise` in the repository.** Smart-home control where the color picker literally re-tints the app theme — script tags only, zero tooling.

## Screens

- Rooms — device card grid with power switches and status dots
- Lighting — per-zone brightness and colour-temperature sliders with live readouts
- Ambience — inline color picker that re-tints --md-sys-color-* roles on :root in JS
- Energy — circular/linear meters and three 14-day sparklines
- Device settings — bottom sheet overlay opened from any device card

## Run it

```bash
git clone https://github.com/awc-ui/core
cd core && pnpm install
pnpm --filter @awc-ui/showcase-hearthwise dev
```

The app's `README.md` documents its structure and any framework-specific
wiring. Like every showcase app, it is styled exclusively with `--md-sys-*`
tokens — retheme it by changing one seed in the
[theme generator](/theme-generator/).
