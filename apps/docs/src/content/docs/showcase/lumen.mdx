**Next.js · `apps/showcase-lumen` in the repository.** Retail banking: sparkline balances, spending breakdown, an OTP-confirmed transfer flow, and budget meters — mobile-first.

## Screens

- / — Accounts overview (balance cards + sparklines, spending pie chart, recent activity list)
- /transactions — md-table with expandable rows, docked md-search with suggestions, md-chip category filters
- /transfer — linear vertical md-stepper: recipient md-select (filterable), amount md-number-field (USD), md-otp-field confirm, md-snackbar success
- /budgets — md-meter per category with status colors, edit md-slider inside md-bottom-sheet, md-snackbar confirmation

```bash
cd core && pnpm install
pnpm --filter @awc-ui/showcase-lumen dev
```
