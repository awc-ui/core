**Nuxt · `apps/showcase-tessellate` in the repository.** Online course platform: catalog, accordion syllabus, progress dashboard, and a stepper-driven quiz.

## Screens

- Catalog (/) — md-card course grid with readonly md-rating, md-chip topic tags and filter chips, docked md-search with keyboard-navigable results
- Course (/courses/[slug]) — md-tabs + md-tab-panels (Lessons/About/Reviews), md-accordion syllabus, enroll md-button, review md-cards; graceful not-found fallback
- My progress (/progress) — per-course linear md-progress-indicator, circular md-meter overall completion, md-bar-chart of quiz scores (series fed as JS props after client define)
- Quiz (/quiz) — linear md-stepper with one md-radio question per md-step, Continue gated via next-disabled until answered, results md-card with score md-meter and per-question verdicts, retake flow
