Ten complete applications live in the repository under `apps/showcase-*`, each
a coherent multi-screen product built end-to-end with AWC UI and nothing else.
They exist to answer one question: *can this library carry a whole app, not
just a widget?* Each app's page below lists its screens, the components it
exercises, and how to run it locally.

This section also hosts the proof pages — live demonstrations of the claims
the library makes about [server-side rendering](/showcase/ssr/) and
[accessibility](/showcase/a11y-lab/).
