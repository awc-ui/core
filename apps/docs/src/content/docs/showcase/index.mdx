A component gallery shows you parts. These are whole applications: real
navigation, real drill-downs, real data density — the conditions a component
library actually has to survive.

Each one is built once and shipped in **every supported framework** — React,
Vue, Angular, Svelte, Astro and plain HTML with no framework at all. Open it in
React, switch to Angular or Svelte from inside the app, and you are looking at
the same screens and the same data rendered by a different stack. Not a port
each time: the data, the translations, the derived series and the table layouts
all come from one shared package, so the only thing that differs between the six
is the view layer.

The control bar in each app also flips **theme, density, text direction and
language** at runtime, so you can see how the components behave under conditions
most demos never show.

## Applications

### [Credit Risk Console](/showcase/credit-risk/)

A wholesale-banking credit risk workbench for the fictional **Aurelia Bank** —
portfolio exposure that drills down through sectors, counterparties, facilities
and covenants, with a watchlist and stress-testing scenarios.

Built to stress the parts of a library that dashboards usually avoid: dense
sortable tables, deep breadcrumb trails, charts fed from the same data, corporate
group hierarchies, and a full translation layer including a right-to-left
language.
