Some claims deserve more than prose. The pages here are running
demonstrations you can check yourself:

- **[Accessibility lab](/showcase/a11y-lab/)** — runs axe-core in *your*
  browser against live components and shows you the result, rather than asking
  you to trust a badge.
- **[SSR that actually paints](/showcase/ssr/)** — the server-rendered pane on
  that page really is server-rendered; view-source and look for
  `<template shadowrootmode="open">`.

A gallery of complete applications built with AWC UI is being rebuilt and will
land here. In the meantime, the [recipes](/recipes/) cover the same ground one
screen at a time — each with a live demo and copy-paste code for every
supported framework.
