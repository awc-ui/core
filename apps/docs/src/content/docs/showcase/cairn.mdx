**SvelteKit · `apps/showcase-cairn` in the repository.** Lightweight project tracker: board/list toggle, side-sheet task detail, sprint burndown, quick-create FAB menu.

## Screens

- Tasks (/) — md-segmented-button-set board/list toggle; list = md-table with md-chip statuses and md-avatar assignees; board = four status columns of interactive md-cards; task click opens a modal md-side-sheet with md-tabs (Details / Checklist / Activity)
- Sprint (/sprint) — burndown md-bar-chart (Remaining vs Ideal story points per day), circular sprint-completion indicator, per-goal linear md-progress-indicators on cards
- Global (all screens) — quick-create md-fab + md-fab-menu (Task / Milestone / Note) with md-snackbar confirmations
