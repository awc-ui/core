These files are the same fonts used by apps/native-playground through
apps/smart-home/public/fonts. No font conversion or glyph substitution is used.

Roboto Regular, Medium and Bold: roboto-latin-400-normal.woff2 and
roboto-latin-500-normal.woff2 and roboto-latin-700-normal.woff2. License: roboto-LICENSE.txt.

Material Symbols Outlined: material-symbols-outlined.woff2.
License: material-symbols-LICENSE.txt.

NativeFonts.swift registers them only within the consumer process using CoreText.
