The Android md-button adapter bundles the same Roboto Latin 400/500 and Material Symbols Outlined font data as the web/SwiftUI implementation. These TTF files were losslessly decompressed from the repository WOFF2 files using FontTools 4.66.1 and Brotli 1.2.0; these are build-time conversion tools only, not runtime dependencies. Original source: packages/native-ios/Sources/AWCUI/Resources/Fonts. See the accompanying original font licenses.
