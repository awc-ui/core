# Android `md-button-group` parity record

Source: `packages/core/src/components/md-button-group/md-button-group.tsx` and `.css`.
Implementation: `NativeButtonGroup.kt`, `AWCGroups.kt`, `AWCButtonGroupAppearance.kt`, shared button/icon-button/focus integration, `AWCButtonGroupTree.kt` and the live Android host.

## Implemented contract

- Seven source properties: `variant`, `size`, `shape`, `selectionMode`, `required`, `fullWidth`, `density`.
- Native default composable slot accepts real `md-button` and `md-icon-button` children, including nested groups and arbitrary native wrappers. All ancestor groups coordinate descendant selection and focus. The initial outer group owns synchronized child toggle, size, shape and connected properties; later watched group changes become the latest synchronization owner, matching the measured Web lifecycle. Local negative child density overrides inherited group density.
- Direct-child layout rules remain separate from descendant coordination: connected corner tables, the connected 48dp floor and group max-height apply only to directly slotted controls. Wrapped descendants still receive synchronized properties without acquiring those direct-child CSS rules.
- Standard source gaps follow all five size/density ladders; connected seam stays 2dp. The seven public style hooks map to `AWCButtonGroupAppearance`: gap, width/min/max width, height/min/max height. The private `_unset` sentinel is excluded.
- No wrapping. Full-width flex divides content width before adding each child's padding/border; explicit minimum widths freeze. Ordinary buttons stretch vertically subject to minimum height; icon buttons retain definite height. A smaller group height can leave children overflowing, while max-height caps their floor as the source does.
- Connected corners use the group's selected/pressed tokens over child radius hooks, including mixed child types and RTL. Standard motion grows the active child and reduces immediate neighbors for a 400ms animation with its peak at 150ms (minimum-width floors can limit neighbor shrinkage); required selected children skip it. The source installs these motion listeners only when initially standard; that behavior is retained.
- Raw click reconciliation happens after the child action, including canceled and soft-disabled/loading child actions. `required` can reselect the clicked child. Every raw click emits one `mdSelectionChange` per ancestor group, inner first, including unchanged deltas. Diffing uses the previous event snapshot, retaining duplicate/empty values.
- Focus uses the recent child, selected single-select child, then first enabled child. Left/Right wrap with RTL reversal; Home/End choose endpoints. Hard-disabled children are skipped. Keyed child reordering updates traversal and state order without remounting. Public Compose tree traversal preserves authored descendant order independently from screen position, RTL and wrapper layout. Nested arrow/Home/End handling follows the original target through inner-to-outer groups; the outer handler supplies the final focus target.
- `AWCButtonGroupStateScope` reports actual ordered booleans independently from value-based events and clears its binding on disposal without clearing a newer owner. Live frame `buttonGroupSelection` is captured with draw state and omitted if selection changes during asynchronous PixelCopy.

## Boundaries

Composition and native focus replace DOM nodes and event objects. Native ancestor membership and layout-tree traversal replace DOM descendant queries. The source exposes no component methods or CSS shadow parts. Native event details omit DOM `originalEvent`; actual native input metadata remains attached to the child action. Typography rendering may differ between platforms.
